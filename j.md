J is an array oriented programming language, i.e., arrays are the main unit of computation. 
It was created by [Kenneth E. Iverson](https://en.wikipedia.org/wiki/Kenneth_E._Iverson) in 1990 as a successor to APL.
See how to install & run J at [JSoftware website](https://code.jsoftware.com/wiki/System/Installation).
